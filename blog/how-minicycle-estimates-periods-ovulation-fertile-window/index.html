Cycle prediction

How MiniCycle estimates periods, ovulation, and the fertile window

MiniCycle uses a modest algorithm: recent period starts first, research-informed defaults second, and clear visual labels so estimates do not look like recorded facts.

Recent records first

A cycle length is the number of days from one period start to the next. When records exist, MiniCycle focuses on recent starts instead of treating one lifetime average as fixed. With enough intervals, it trims one unusually short and one unusually long interval before taking a median-style value. This reduces the effect of travel, stress, illness, or missed logging.

Fallbacks stay simple

If you manually set cycle length or period length, that setting takes priority. Without enough history, MiniCycle uses practical defaults so the calendar remains useful on day one. The app then estimates the next period and counts backward to show an estimated ovulation day.

Fertile window labels

Published research shows real cycles vary substantially. MiniCycle therefore treats ovulation and fertile-window labels as planning cues. It marks a window around estimated ovulation, but it does not claim medical certainty.

MiniCycle predictions are not medical advice, contraception, diagnosis, or fertility treatment.
