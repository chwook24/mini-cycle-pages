Forgot to log a period? How to repair the record in MiniCycle

Published August 23, 2026 by MiniCycle·3 min read

If a period came and went without being recorded, you do not need to reset MiniCycle. Add the dates you remember and check the result. If the exact start is uncertain, keep that uncertainty visible rather than turning a guess into a precise-looking record.

What a missing record does to the calendar

MiniCycle counts forward from the most recent period start you saved. If one cycle is missing, the app cannot know that bleeding happened. It continues from the older record and may eventually show a later predicted cycle as the next one.

The missing interval is not filled in automatically. A predicted date is never saved as an actual period start, so the calendar may look orderly while the record underneath it still has a gap.

Add the missed start when you know the date

Go back to the month in the calendar, select the day the period began, and choose period start. MiniCycle can add a past record; you do not have to enter periods in chronological order.

If the new start is within seven days of an existing start, the app treats it as a possible correction and asks before replacing the old record. A date eight or more days away is added as a separate period.

Check the end date as well

After you add a start, MiniCycle fills an end date from the current period-length setting. That is only a starting value. If you remember the last day of bleeding, select it and choose period end.

A saved period can span at most 14 days, including the start day. If the dates do not fit that range, the app will not save the end. Check nearby records too, especially if an older period was left open longer than it should have been.

Do not turn a rough memory into an exact date

If you remember the week but not the day, there is no perfect repair. MiniCycle does not have an ‘approximate start’ label, and any date saved as a period start is used in the cycle calculation.

Record a start only when you are reasonably confident in it. Otherwise, leave the gap and treat the predictions as approximate until more reliable starts are available. A memo can preserve what you remember, but it does not exclude an uncertain date from calculations.

What changes after the record is added

The new start becomes part of the recent interval history, so the estimated cycle length and future period, ovulation, and fertile-window dates may change. MiniCycle also reschedules relevant local notifications.

The app updates its shared widget data and asks iOS to reload the widget. iOS controls the redraw time, so the previous date may remain on the home screen for a while.

Forgetting to log is different from missing a period

This guide is about bleeding that happened but was not recorded. If a period did not happen, do not create a record to make the calendar match an old prediction. Leave the record as it is.

MiniCycle can organize dates, but it cannot explain why bleeding was late, absent, or unusual. Predictions are reference information, not contraception or pregnancy confirmation. If the pattern itself concerns you, discuss it with a clinician and be clear about which dates are recorded and which are uncertain.
