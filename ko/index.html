MiniCycle

아이폰 홈 화면에서 바로 확인하는 간단한 생리 캘린더.

생리 날짜를 기록하고, 배란일과 가임기 추정을 확인하고, 깔끔한 홈 화면 위젯으로 현재 주기 상태를 빠르게 봅니다.

App Store에서 받기 블로그 읽기 지원 받기

빠른 주기 확인을 위해 만들었습니다

MiniCycle은 월간 캘린더, 일별 기록, 예측, 위젯을 중심에 두고 불필요한 기능을 줄였습니다.

  • 생리 시작일과 종료일 기록
  • 생리 예정일, 배란일, 가임기 표시
  • 최근 기록 기반 주기와 생리 기간 통계
  • 기본 로컬 저장, 선택적 iCloud 저장

블로그 글

주기 건강

생리 중에도 임신이 될 수 있을까요

생리 중 임신은 드물지만 불가능하지 않습니다. 주기가 짧고 생리가 길 때 특히 그렇습니다. 왜 가능한지, 달력 예측이 왜 피임이 아닌지 정리했습니다.

주기 통계

MiniCycle 통계 탭은 최근 주기를 어떻게 보여줄까요

MiniCycle 통계 탭은 저장된 날짜에서 최근 주기 길이와 생리 기간을 요약하고, 최근 데이터 24개까지 보여줍니다. 무엇이 어떻게 계산되는지, 통계로 알 수 없는 것을 정리했습니다.

주기 건강

생리혈 색깔, 갈색이나 검은색도 정상일까요

생리혈이 갈색이나 검은색을 띠는 건 대개 피가 나오기까지 시간이 걸렸다는 뜻입니다. 분홍·빨강·갈색이 다 정상인 이유와, 색보다 정작 살펴야 할 것을 정리했습니다.
