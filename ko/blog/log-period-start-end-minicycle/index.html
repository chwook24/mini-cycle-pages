MiniCycle에 생리 시작일과 종료일 기록하는 법

2026년 6월 16일 MiniCycle 작성·약 3분 읽기

MiniCycle에서는 달력에서 날짜를 선택한 뒤 생리 시작 또는 생리 종료를 기록합니다. 시작일을 입력하면 현재 생리 기간 설정을 이용해 종료일이 먼저 채워지고, 나중에 실제 종료일로 수정할 수 있습니다. 기존 기록과 겹칠 때의 처리와 잘못 입력한 날짜를 고치는 방법도 함께 설명합니다.

생리 시작 기록하기

달력에서 출혈이 시작된 날짜를 선택하고 ‘생리 시작’을 누릅니다. MiniCycle은 현재 생리 기간 설정을 이용해 해당 날짜부터 하나의 생리 구간을 만듭니다. 기본값이 5일이면 6월 3일에 시작한 기록은 우선 6월 7일까지 표시됩니다.

자동 모드에서는 최근에 종료된 생리 기록으로 기간을 추정하고, 수동 모드에서는 사용자가 정한 일수를 사용합니다. 먼저 채워진 종료일이 실제와 다르면 나중에 수정하세요.

생리 종료 기록하기

출혈이 끝난 마지막 날짜를 선택하고 ‘생리 종료’를 누르면 해당 구간의 종료일이 바뀝니다. 종료일은 시작일과 같거나 그 뒤여야 합니다.

한 생리 구간은 시작일과 종료일을 모두 포함해 최대 14일까지 저장할 수 있습니다. 시작 기록이 없거나 허용 범위를 벗어나면 앱에 안내 메시지가 표시됩니다.

가까운 시작일을 다시 입력한 경우

새로 선택한 시작일이 기존 시작일과 7일 이내이면 MiniCycle은 별도의 생리를 추가하지 않고 기존 기록을 바꿀지 확인합니다. 예를 들어 6월 3일을 6월 4일로 고치면 하나의 생리 기록으로 남습니다.

기존 시작일과 8일 이상 떨어진 날짜는 새 생리로 추가됩니다. 변경 확인 창이 나타나면 날짜를 확인한 뒤 진행하세요.

생리 구간이 겹치는 경우

두 생리 구간이 같은 날짜를 포함하면 달력 표시는 시작일이 더 최근인 구간을 우선합니다. 기록이 자동으로 합쳐지거나 이전 구간이 삭제되는 것은 아닙니다.

겹침이 입력 실수라면 기존 구간의 시작일이나 종료일을 고치거나, 해당 생리 상세 카드의 휴지통 버튼으로 잘못된 구간을 삭제하세요.

이 날짜가 무엇을 바꾸나요

시작일은 다음 예정일과 배란일·가임기 추정의 기준이 됩니다. 배란일은 다음 예정일에서 주기 길이에 따라 정한 9–14일의 황체기를 빼서 추정하고, 가임기 표시는 예상 배란일 5일 전부터 다음 날까지 이어집니다.

이 계산은 진단, 피임, 임신 확인에 사용할 수 없습니다. 기록은 기본적으로 기기에 저장되며, iCloud 동기화를 켜면 Apple CloudKit을 통해 본인 iCloud에도 사본이 저장됩니다.
