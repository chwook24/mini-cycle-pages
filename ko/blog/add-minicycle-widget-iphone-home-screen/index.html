MiniCycle 위젯을 아이폰 홈 화면에 추가하는 방법

2026년 6월 15일 MiniCycle 작성·약 3분 읽기

MiniCycle은 iPhone 홈 화면에 추가할 수 있는 작은 크기의 위젯을 제공합니다. 위젯에는 오늘이 포함된 4주 달력과 생리 기록, 예상 생리, 추정 가임기·배란일이 표시됩니다. 추가 방법과 앱 화면과 바로 같아 보이지 않을 때 확인할 내용을 정리했습니다.

작은 위젯 추가하기

홈 화면의 빈 곳을 앱 아이콘이 흔들릴 때까지 길게 누릅니다. ‘편집’과 ‘위젯 추가’를 차례로 누른 뒤 MiniCycle을 검색합니다. MiniCycle 위젯을 추가해 원하는 위치에 놓고 ‘완료’를 누릅니다.

MiniCycle은 현재 작은 정사각형 위젯만 지원합니다. 중간이나 큰 크기는 선택할 수 없습니다. iOS 버전에 따라 버튼 이름은 조금 다를 수 있으므로 아래 Apple 안내도 함께 확인하세요.

위젯에 표시되는 내용

위젯은 오늘이 포함된 4주 달력을 보여 줍니다. 앱에 저장된 생리 기록과 예측 설정을 사용해 생리일, 추정 가임기, 추정 배란일을 표시합니다. 앱에서 선택한 날짜를 위젯에 따로 표시하지는 않습니다.

주 시작 요일과 언어 설정은 앱과 공유합니다. 계산 로직도 같지만 iOS가 이전 타임라인을 잠시 유지할 수 있으므로 앱과 위젯이 항상 같은 순간에 바뀐다고 보장할 수는 없습니다.

위젯이 비어 있거나 오래된 상태로 보일 때

생리 시작일을 한 번도 기록하지 않았다면 위젯에는 기록을 시작하라는 기본 화면이 표시됩니다. MiniCycle에서 시작일을 기록하거나 잘못된 날짜를 수정한 뒤 홈 화면으로 돌아가세요.

앱을 열면 최신 공유 데이터를 저장하고 위젯 갱신을 요청하지만 실제 반영 시점은 iOS가 정합니다. 잠시 기다려도 바뀌지 않으면 위젯을 삭제한 뒤 다시 추가해 보세요. 위젯에는 별도의 주 시작 요일 설정이 없으며 앱 설정을 그대로 읽습니다.

위젯에 표시되지 않는 내용

위젯에는 날짜별 메모와 성생활 기록이 표시되지 않으며, 날짜를 추가하거나 수정하는 버튼도 없습니다.

생리 기록과 예상 날짜를 빠르게 확인할 때는 위젯을 사용하고, 기록을 추가·수정하거나 메모를 볼 때는 앱을 여세요.
